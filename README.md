# 富山湾 航空写真×水深マップ

富山湾の**航空写真**に**水深の等深線**を重ねて、岸近くの根・藻場・**かけ上がり（急深）**を目で探す無料ツールです。カヤックフィッシングの下調べ用に作りました。

公開URL（予定）: https://sanzai-mokujiroku.github.io/kayak-depth-map/

## できること

- 国土地理院のシームレス航空写真を表示（岸近くの澄んだ水は根・藻場が写る＝実質の高解像度）
- 水深の等深線を重ね表示。**線が詰まった帯＝かけ上がり（急深）**が一目で分かる
  - カヤック帯（5・10・20・30・50m）はカラーで強調、100m以深は文脈として控えめに
- 地図をタップすると、その地点の緯度・経度・**推定水深**を表示
- PWA対応。一度見た海域は航空写真タイルもキャッシュされ、電波の弱い海上でも表示できる

## データと精度について

- **航空写真**：国土地理院 シームレス空中写真（`seamlessphoto`）。
- **水深**：GEBCO 2020（[opentopodata.org](https://www.opentopodata.org/) 経由）。**約450m格子と粗い**ため、水深は「おおまかな目安・かけ上がりの帯」を示す文脈として使う。
  細かい根・地形は航空写真で、**実際の水深は現場の魚探で**確認すること。
- 富山湾ぶんの水深は `bake_depth.py` で事前取得し `depth-toyama.json`（海面下のみ）に焼き込み済み。
  ブラウザからGEBCOを直接呼ぶとCORSで弾かれるため、この事前ベイク方式にしている（ネット不要で動く）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 本体（バニラJS＋Leaflet）。等深線はマーチングスクエア法で生成→端点連結→Chaikin平滑化 |
| `depth-toyama.json` | 富山湾の事前ベイク水深グリッド |
| `bake_depth.py` | 水深グリッドを作り直すスクリプト（GEBCO/opentopodata） |
| `vendor/leaflet/` | Leaflet 1.9.4（オフライン用にローカル同梱） |
| `sw.js` | サービスワーカー。アプリ外枠＋水深＋航空写真タイルをキャッシュ |
| `make_icon.py` | アイコン生成（外部ライブラリ不要） |

## 更新時の注意

- 見た目や判定ロジックを変えたら、`sw.js` の `CACHE` の版番号を上げる（上げないと古い画面が配信され続ける）。
- 水深を取り直すときは `python3 bake_depth.py`（範囲・格子間隔はスクリプト先頭で調整）。
